# ESP32-S31-Function-CoreBoard-1

本项目增加 ESP32-S31 的构建支持，使用 ESP-IDF 6.1 的预览目标 `esp32s31`。
该芯片是双核 RISC-V，不兼容 ESP32-S3 的 Xtensa 固件。

## 构建和刷写

先激活 ESP-IDF 6.1。此电脑可以使用：

```bash
source "/Users/weijiangchen/.espressif/tools/activate_idf_v6.1.sh"
```

在项目根目录执行：

```bash
idf.py --preview -B build-s31 \
  -D IDF_TARGET=esp32s31 \
  -D SDKCONFIG=sdkconfig.s31 \
  -D SDKCONFIG_DEFAULTS=sdkconfig.s31.defaults build

idf.py --preview -B build-s31 -p PORT flash monitor
```

将 `PORT` 替换为实际串口。后续设置修改使用
`idf.py --preview -B build-s31 menuconfig`，然后重新运行构建命令。
ESP32-S31 尚为预览目标，需要 `--preview`。当前官方 PlatformIO 板卡列表没有
这块板，S31 使用原生 ESP-IDF 构建。

## 板卡接线

- 键盘或鼠标插入板载 **USB-A**；该接口连接芯片的 USB 2.0 OTG 控制器。
- 通过 **USB-C to UART** 或 **USB Serial/JTAG** 接口供电、烧录。
- USB-A 供电开关 TPS2051C 的 EN 由硬件上拉启用，限流 500 mA，无需 GPIO 控制。
- 板载 WS2812 状态灯使用 **GPIO60**、GRB 顺序；数据线经晶体管反相，已启用输出反相。
- 蓝牙配对方法与 ESP32-S3 相同，设备名称为 `BLE HID`。

## 配置与兼容性

保留 USB Host + Bluedroid BLE HID 架构，继续使用同一套输入解析、设备切换和鼠标累加代码。
S31 使用独立的 `sdkconfig.s31.defaults`、`sdkconfig.s31`、`build-s31` 和
`dependencies.lock.esp32s31`，避免加载原有 `sdkconfig.defaults` 中的 S3/Xtensa 配置。
S31 配置采用 BLE-only 控制器、16 MB Flash 和较大的单应用分区；不依赖 PSRAM。
USB HID 驱动升级至 1.2.1，该版本正式将 `esp32s31` 列为支持目标。

`menuconfig → BLE_keyboard_mouse` 提供 LED GPIO、GRB 顺序和信号反相选项。
S3 默认仍为 GPIO48、RGB 顺序、不反相。RMT 缓冲区大小按芯片能力设置。

USB Host 1.5.0 在 S31 上使用高速 OTG 控制器。直接连接全速/低速 HID 设备可用，
但上游 USB 栈暂不支持高速 Hub 下全速/低速设备所需的 split transactions。
需要同时连接键鼠时，请使用 USB 1.1 全速 Hub，并进行真机验证。
USB Host 1.6.0 的 `fsls_only` 选项还要求新版 ESP-IDF HAL；当前 6.1 HAL
缺少该接口，不能直接启用，否则初始化返回 `ESP_ERR_NOT_SUPPORTED`。

## 验证与回退

ESP-IDF 6.1 完整构建通过：S31 固件 1,272,800 字节，应用分区剩余 263,200 字节（17%）；
S3 回归构建通过，固件 827,312 字节，原 1 MiB 应用分区剩余 21%。
输入协议、鼠标累加器、USB 恢复、BLE 会话和 USB 集成五组主机回归全部通过。

尚未烧录或进行真机验收。请验证 LED 四种状态、BLE 配对及断连重连、键鼠输入和 USB 热插拔。

回退到 S3 时使用原有构建命令和 `build/`、`sdkconfig`。
如需撤销 S31 支持，恢复本次修改的文件并移除新增 S31 配置、锁文件及本说明。
